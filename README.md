# IF25-22014-Pengembangan-Aplikasi-Web
Mata kuliah ini memberikan pemahaman atas konsep dan keahlian dalam mengembangkan sebuah website yang berfokus pada pengembangan aplikasi di sisi client dan server. Pengembangan aplikasi web pada mata kuliah ini menggunakan kerangka kerja Python Pyramid pada aplikasi server dan React Js pada aplikasi client
