# Hands-on Pertemuan 9: Pemrograman Python

Mengolah data nilai mahasiswa dengan Python: tipe dan logika, list dan dict, fungsi bertipe, modul, JSON, lalu menyiapkan virtual environment untuk FastAPI.

| Tingkat | Waktu | Yang dilatih | Sub-CPMK |
|---|---|---|---|
| Tingkat 1, Dasar | 10 menit | tipe data, operator, percabangan, dan perulangan | 9.1 |
| Tingkat 2, Menengah | 15 menit | list, dict, comprehension, dan fungsi bertipe | 9.1, 9.2 |
| Tingkat 3, Tantangan | 10 menit | modul, JSON, set, dan dict hasil rekap | 9.2 |
| Pengayaan | sisa | virtual environment dan `requirements.txt` untuk P11 | 9.2 |

Soal ada di `Lembar Hands-on P9.pdf`. Setelah setiap tingkat, tukar laptop dengan teman sebelah untuk saling memeriksa sebelum lanjut. Berkas awal ada di `starter/`; salin foldernya, lalu kerjakan bagian bertanda `TODO`. Angka $A$ adalah digit terakhir NIM (kalau 0, pakai 5) dan $B$ digit kedua dari belakang (kalau 0, pakai 3).

## Persiapan

Pastikan `python --version` menampilkan 3.11 atau lebih baru (di sebagian laptop perintahnya `python3`). Semua berkas ada di `starter/`; jalankan dengan `python namaberkas.py` dari dalam folder itu.

Solusi rujukan (`solusi/`) dan kunci (`kunci/`) dipegang pengajar dan tidak ikut di repo.
