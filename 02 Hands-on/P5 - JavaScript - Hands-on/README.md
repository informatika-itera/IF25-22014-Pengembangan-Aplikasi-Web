# Hands-on Pertemuan 5: Pemrograman JavaScript

Membangun aplikasi daftar tugas kuliah: tipe data dan logika di Console, data dalam array of object, menampilkannya ke DOM, lalu menanggapi formulir dan klik.

| Tingkat | Waktu | Yang dilatih | Sub-CPMK |
|---|---|---|---|
| Tingkat 1, Dasar | 10 menit | variabel, tipe data, percabangan, dan perulangan di Console | 5.1 |
| Tingkat 2, Menengah | 15 menit | array of object, fungsi, dan menampilkan data ke DOM | 5.1, 5.2 |
| Tingkat 3, Tantangan | 10 menit | event submit dan klik: tambah, coret, hapus tugas, dengan validasi | 5.2 |
| Pengayaan | sisa | menyimpan daftar di `localStorage` | 5.2 |

Soal ada di `Lembar Hands-on P5.pdf`. Setelah setiap tingkat, tukar laptop dengan teman sebelah untuk saling memeriksa sebelum lanjut. Berkas awal ada di `starter/`; salin foldernya, lalu kerjakan bagian bertanda `TODO`. Angka $A$ adalah digit terakhir NIM (kalau 0, pakai 5) dan $B$ digit kedua dari belakang (kalau 0, pakai 3).

## Persiapan

Buka `starter/index.html` di browser dan biarkan DevTools tab Console terbuka. Semua kode ditulis di `starter/app.js`.

Solusi rujukan (`solusi/`) dan kunci (`kunci/`) dipegang pengajar dan tidak ikut di repo.
