# Hands-on Pertemuan 3: Mengenal CSS

Memberi gaya pada halaman profil dari P2 dengan satu berkas CSS eksternal: variabel warna dari NIM, selektor, specificity, dan model box.

| Tingkat | Waktu | Yang dilatih | Sub-CPMK |
|---|---|---|---|
| Tingkat 1, Dasar | 10 menit | menautkan CSS eksternal, variabel warna dari NIM, tipografi dasar | 3.1 |
| Tingkat 2, Menengah | 15 menit | selektor keturunan, pseudo-kelas, baris tabel bergantian, dan prediksi specificity | 3.1, 3.2 |
| Tingkat 3, Tantangan | 10 menit | model box: kartu dengan lebar tampil tepat, singkatan sisi | 3.2 |
| Pengayaan | sisa | tema gelap otomatis dengan variabel dan `prefers-color-scheme` | 3.1 |

Soal ada di `Lembar Hands-on P3.pdf`. Setelah setiap tingkat, tukar laptop dengan teman sebelah untuk saling memeriksa sebelum lanjut. Berkas awal ada di `starter/`; salin foldernya, lalu kerjakan bagian bertanda `TODO`. Angka $A$ adalah digit terakhir NIM (kalau 0, pakai 5) dan $B$ digit kedua dari belakang (kalau 0, pakai 3).

## Persiapan

Buka `starter/index.html` di browser. Semua gaya ditulis di `starter/style.css`; `starter/menang.html` dipakai untuk misi coba dulu.

Solusi rujukan (`solusi/`) dan kunci (`kunci/`) dipegang pengajar dan tidak ikut di repo.
