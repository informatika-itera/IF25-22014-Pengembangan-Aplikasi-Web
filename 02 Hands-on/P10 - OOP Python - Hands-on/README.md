# Hands-on Pertemuan 10: OOP di Python

Memodelkan data akademik dengan OOP: class Mahasiswa dengan validasi, property untuk nilai, pewarisan pengguna, polymorphism, abstract class penilaian, dan perbandingan dengan Pydantic.

| Tingkat | Waktu | Yang dilatih | Sub-CPMK |
|---|---|---|---|
| Tingkat 1, Dasar | 10 menit | class, konstruktor dengan validasi, atribut, dan method | 10.1 |
| Tingkat 2, Menengah | 15 menit | encapsulation dengan property, inheritance, dan polymorphism | 10.2 |
| Tingkat 3, Tantangan | 10 menit | abstract class dan perhitungan nilai akhir | 10.2 |
| Pengayaan | sisa | model Pydantic sebagai persiapan P11 | 10.2 |

Soal ada di `Lembar Hands-on P10.pdf`. Setelah setiap tingkat, tukar laptop dengan teman sebelah untuk saling memeriksa sebelum lanjut. Berkas awal ada di `starter/`; salin foldernya, lalu kerjakan bagian bertanda `TODO`. Angka $A$ adalah digit terakhir NIM (kalau 0, pakai 5) dan $B$ digit kedua dari belakang (kalau 0, pakai 3).

## Persiapan

Aktifkan virtual environment dari P9. Kerjakan di `starter/akademik.py`, jalankan dengan `python akademik.py`. Untuk pengayaan pasang `pip install pydantic`.

Solusi rujukan (`solusi/`) dan kunci (`kunci/`) dipegang pengajar dan tidak ikut di repo.
