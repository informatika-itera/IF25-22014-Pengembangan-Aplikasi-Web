# Hands-on Pertemuan 7: Kerangka Kerja React JS

Membangun aplikasi KRS kecil dengan React di Next.js (App Router): komponen kartu dengan props dan CSS Modules, state total SKS, pengambilan data dengan keadaan memuat dan gagal, routing ke halaman detail, formulir terkendali, dan Context.

| Tingkat | Waktu | Yang dilatih | Sub-CPMK |
|---|---|---|---|
| Tingkat 1, Dasar | 10 menit | komponen dengan props, CSS Modules, dan `map` dengan `key` | 7.1 |
| Tingkat 2, Menengah | 15 menit | state total SKS dan pengambilan data dengan keadaan memuat dan gagal | 7.1, 7.2 |
| Tingkat 3, Tantangan | 10 menit | halaman dinamis, Link, tabel, dan formulir terkendali | 7.2 |
| Pengayaan | sisa | Context untuk total SKS di menu atas | 7.2 |

Soal ada di `Lembar Hands-on P7.pdf`. Setelah setiap tingkat, tukar laptop dengan teman sebelah untuk saling memeriksa sebelum lanjut. Berkas awal ada di `starter/`; salin foldernya, lalu kerjakan bagian bertanda `TODO`. Angka $A$ adalah digit terakhir NIM (kalau 0, pakai 5) dan $B$ digit kedua dari belakang (kalau 0, pakai 3).

## Persiapan

Butuh Node.js versi LTS. Di folder `starter/` jalankan `npm install` lalu `npm run dev`, dan buka `http://localhost:3000`. Data contoh ada di `public/matkul.json`; mulai P11 data diganti dari API FastAPI.

Solusi rujukan (`solusi/`) dan kunci (`kunci/`) dipegang pengajar dan tidak ikut di repo.
