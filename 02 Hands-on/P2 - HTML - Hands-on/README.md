# Hands-on Pertemuan 2: Mengenal HTML

Membangun halaman profil mahasiswa dari kerangka `div` menjadi halaman HTML semantik yang valid, lalu (pengayaan) menerbitkannya ke GitHub Pages.

| Tingkat | Waktu | Yang dilatih | Sub-CPMK |
|---|---|---|---|
| Tingkat 1, Dasar | 10 menit | kerangka dokumen, heading, paragraf, gambar dengan `alt`, tautan | 2.1 |
| Tingkat 2, Menengah | 15 menit | mengganti `div` dengan elemen semantik, tabel jadwal dengan baris judul | 2.2 |
| Tingkat 3, Tantangan | 10 menit | formulir dengan `label` dan tipe input HTML5, lalu nol error di validator | 2.1, 2.2 |
| Pengayaan | sisa | menerbitkan halaman ke GitHub Pages | 2.2 |

Soal ada di `Lembar Hands-on P2.pdf`. Setelah setiap tingkat, tukar laptop dengan teman sebelah untuk saling memeriksa sebelum lanjut. Berkas awal ada di `starter/`; salin foldernya, lalu kerjakan bagian bertanda `TODO`. Angka $A$ adalah digit terakhir NIM (kalau 0, pakai 5) dan $B$ digit kedua dari belakang (kalau 0, pakai 3).

## Persiapan

Pasang VS Code dan ekstensi Live Server (opsional). Buka `starter/index.html` di browser, atau klik kanan lalu Open with Live Server. Siapkan satu gambar apa saja, simpan sebagai `starter/foto.jpg`.

Solusi rujukan (`solusi/`) dan kunci (`kunci/`) dipegang pengajar dan tidak ikut di repo.
